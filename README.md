# Metrics

Репозиторий независимых сервисов с модульной организацией кода для сбора метрик
пользовательских сценариев. Каждый модуль в `service/` имеет свою точку входа,
бинарник и контейнер; Go-модуль и инструменты разработки общие.

## Модули

| Модуль                                  | Назначение                     | Статус                                                    |
|-----------------------------------------|--------------------------------|-----------------------------------------------------------|
| [user-auth](service/user-auth/README.md) | Измерение сценария входа в МИС | Каркас; обработка событий и экспорт метрик не реализованы |

Сборщик метрик создания пациента планируется отдельно; его кода в проекте пока нет.
