# HTTP-сервер

Общий HTTP-сервер принимает готовый `http.Handler` и управляет listener и
соединениями без привязки к приложению или DI-контейнеру.

[config.Load](config/http.go) явно читает `CORE_HTTP_*`; потребитель также может
передать проверенные настройки напрямую. [bootstrap.New](bootstrap/server.go)
собирает [api.Server](api/server.go) без открытия порта и запуска горутин.

Владелец вызывает `Open`, запускает блокирующий `Serve` в собственной горутине
и наблюдает его результат. При остановке он закрывает приём через `CloseListener`,
вызывает `Shutdown` с общим бюджетом и ожидает завершения `Serve`. При ошибке
`Shutdown` соединения закрываются принудительно; `Close` доступен для явного
принудительного закрытия. Сборка и жизненный цикл приложения user-login —
в [bootstrap приложения](../../cmd/user-login-httpserver/bootstrap/runtime.go).
